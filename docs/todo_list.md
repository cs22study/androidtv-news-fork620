## 📅 版本升級完成回顧 (v6.2.1 ~ v6.2.3)

1. **🎬 直屏短劇與 Shorts 自適應比例防變形 (v6.2.3 - 實機回饋深度優化)**：
   - 監聽 ExoPlayer `onVideoSizeChanged`，綜合考量旋轉度數與像素長寬比，預設 Mode 0 (Fit) 完美維持原生 9:16 直屏長寬比居中呈現，背景採用電影級深邃黑邊 (`#000000`)。
   - 支援三段比例模式（Fit 保持原比 / Stretch 強制全螢幕 / Crop 滿版裁切），支援左側選單按鈕、實體遙控器快捷鍵與 Web 虛擬遙控器一鍵切換並持久化記憶。
2. **⚡ YouTube 流行音樂與點播影片 (VOD) 緩衝卡頓徹底調校 (v6.2.3)**：
   - 客製化調校 ExoPlayer `DefaultLoadControl`（起播緩衝優化至 1.0 秒以加速啟動，重新緩衝優化至 2.5 秒，避免長時間轉圈等候）。
   - `MergingMediaSource` 啟用時間戳校準位移 (`adjustPeriodTimeOffsets=true`) 與持續時間修剪 (`clipDurations=true`)，消除音視軌分離流同步阻斷。
   - `DefaultHttpDataSource` 設定 15s 連線逾時與 Chrome Desktop 標頭，並將預設 YouTube 畫質限制為 `bv*[height<=1080]+ba/b`，避免電視盒拉取 4K 導致解碼卡頓。
3. **🎯 徹底修復頻道總覽選台無法切換 (v6.2.2 - 小米盒子 S 3代實測修復)**：
   - 排除 `ListView` 內部子視圖焦點攔截問題 (`itemsCanFocus = false`、`blocksDescendants`)，建立實體遙控器 `DPAD_CENTER` / `ENTER`、`OnItemClickListener` 與子項點擊三重安全觸發，徹底解決按 OK 無法跳台問題。
2. **📜 YouTube 搜尋歷史紀錄 (v6.2.2 - CSV 持久化儲存)**：
   - 自動將搜尋過的關鍵字儲存至 `youtube_search_history.csv`，內建「機場直播」、「流行音樂」、「穿越短劇」等熱門預設詞。
   - 電視端搜尋彈窗與 Web 後台皆支援一秒點擊標籤直接搜尋，省去遙控器繁瑣注音輸入。
3. **🚪 左側功能選單「退出 APP」 (v6.2.2)**：
   - 側邊欄最下方加入「🚪 退出 APP」功能鍵，點擊直接完全離開 APP，不再二次彈窗詢問。
4. **🌐 TVBox 風格區網遠端管理後台 (Local Web Admin)**：
   - 解決電視遙控器輸入文字痛苦難題，手機瀏覽器開啟 `http://[電視IP]:8080` 即刻管理。
   - 整合自給自足深色儀表板、頻道即時推播、config.txt 編輯器、Cookies 授權與虛擬遙控器。
5. **🎨 介面全域現代化美化**：
   - 左側抽屜選單字體由 `30sp` 調校至 `16sp`，引入壓克力磨砂邊欄與焦點光暈。
   - 頻道總表 (`ChannelListActivity`) 移除 `30sp` 巨大文字，改為舒適 `17sp` 搭配高對比圓角焦點卡片 (`channel_item_selector.xml`)。
   - 新增與設定頻道頁面全數增設頂部「⮌ 返回」與「💾 完成」按鈕，完美支援滑鼠與觸控操作。
6. **🔑 永久固化正式發行簽名金鑰 (覆蓋更新防護)**：
   - 生成持久 `keystore.jks` 納入版控，遞增 `versionCode 60220`，徹底解決 CI 動態金鑰導致之 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 安裝錯誤。
7. **🔄 自動與手動更新檢查機制**：
   - 啟動時非同步靜默檢查，設定頁面支援手動檢查更新並一鍵跳轉 GitHub Releases。
8. **💾 四重頻道清單持久化與 Web 一鍵匯出/匯入**：
   - 建立「外部目錄 + 內部私有目錄 + SharedPreferences + 滾動備份 (.bak)」四重防護，保證 APK 更新升級頻道零遺失。
   - Web 後台提供一鍵下載 `news_channels_backup.json` 與一鍵檔案/貼上匯入功能。

### 優先級一：核心操作與頻道管理強化 (近期推薦)

- [ ] **1. 頻道自訂排序與拖曳重排 (Drag & Drop Reordering)**
  - **說明**：在 Web 後台頻道列表加入拖曳把手，可直接拖拉調整頻道先後順序，並同步更新電視端頻道號碼。
  - **好處**：電視盒使用者可隨心所欲將最常看的 3~5 台排在最前方（0~4 台），開機直接秒播。

- [ ] **2. 頻道台標/圖示支援 (Channel Logo / Icon)**
  - **說明**：在 `config.txt` 與頻道物件中擴充 `logo` 欄位（支援 URL 或本地圖庫資源），並在頻道總表、選單與切台資訊列顯示頻道電視台 Logo。
  - **好處**：大幅提升電視觀看之視覺質感，老人家或小孩即使不讀文字也能一目了然電視台。

- [ ] **3. 頻道分類標籤與群組切換 (Channel Categories / Tags)**
  - **說明**：支援多分類標籤（例如：`新聞台`、`財經台`、`綜合台`、`即時路況/景點 LiveCam`、`自訂喜愛`）。
  - **好處**：當頻道數累積超過 30~50 台時，可透過左右鍵快速切換分類，避免在單一長列表中反覆翻頁。

### 優先級二：串流穩定度與播放體驗 (中期推薦)

- [ ] **4. 串流中斷自動重試與備用線路機制 (Auto-Reconnect & Fallback Streams)**
  - **說明**：部分網路直播（特別是 YouTube 24小時直播台或新聞台換時段）偶爾會發生緩衝中斷。加入指數退避（Exponential Backoff）自動重連機制（1s, 3s, 5s）。
  - **說明 2**：支援備用網址 `backupUrls: []`，若主串流連續失敗 3 次自動無縫切換至備用串流。
  - **好處**：看電視不中斷，免除手動重按切台的困擾。

- [ ] **5. 電子節目表 (EPG / Program Guide) 整合**
  - **說明**：串接台灣正版公視、東森、TVBS 等電視台之公開節目表 API，於切台時在畫面下方橫幅顯示「目前節目」與「下一節目」。
  - **好處**：觀看體驗完全比擬傳統第四台有線電視機上盒。

- [ ] **6. 睡眠定時關閉 / 閒置省電模式 (Sleep Timer)**
  - **說明**：在選單中加入「睡眠定時」（30 分鐘、60 分鐘、90 分鐘或夜間自動暫停）。
  - **好處**：睡前觀看新聞時，時間到達自動暫停播放，避免整夜播放浪費頻寬與電力。

### 優先級三：多端生態與零成本雲端同步 (遠期規劃)

- [ ] **7. 零花費雲端雙向同步 (Google Sheets / GitHub Gist / GAS 整合)**
  - **說明**：遵循專案原則 4（零花費，僅用 GitHub Pages + Google Apps Script + Google Sheets）。
  - **實現方式**：在 Web 後台提供輸入 Google Apps Script Web App URL，電視端可一鍵「上傳至雲端試算表」或「從雲端試算表拉取」。
  - **好處**：家中有客廳電視盒、臥室電視盒與個人手機，只需在手機試算表編輯一次，家中所有設備一鍵全同步！

- [ ] **8. 手機端子母畫面 (Picture-in-Picture, PiP) 支援**
  - **說明**：在手機或平板上點按 Home 鍵返回桌面時，自動縮小為浮動小視窗繼續播放。
  - **好處**：使用者可以一邊回覆 LINE、看網頁，一邊收聽背景新聞直播。

- [ ] **9. 螢幕比例與填滿模式切換 (Aspect Ratio & Zoom Modes)**
  - **說明**：遙控器或介面支援切換「原始比例 (Fit)」、「等比填滿 (Fill/Crop)」、「16:9 延伸」。
  - **好處**：針對部分舊型 4:3 畫面或特殊直向直播串流提供最佳顯示效果。
